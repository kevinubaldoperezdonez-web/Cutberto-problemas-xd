Etiquetas de html

Etiqueta Descripcion Sintaxis Efecto
html Inicia la pagina <html> Hace el documento html
head Guarda datos de la pagina <head> Guarda informacion
title Pone el nombre de la pagina <title> Sale en la pestaña
body Aqui va la pagina <body> Muestra el contenido
h1 Hace un titulo <h1> Hace un titulo grande
h2 Hace otro titulo <h2> Hace un titulo mas chico
p Hace un parrafo <p> Pone texto
br Baja el texto Hola<br>Mundo Hace otra linea
b Pone texto en negrita <b> El texto se ve grueso
i Pone texto en cursiva <i> El texto se inclina
a Hace un link <a href="google.com"> Abre otra pagina
img Pone una imagen <img src="foto.jpg"> Muestra una imagen
ul Hace una lista <ul> Hace lista con puntos
ol Hace una lista con numeros <ol> Hace lista numerada
li Agrega algo a una lista <li> Pone un elemento
div Sirve para juntar cosas <div> Hace un bloque
button Hace un boton <button> Aparece un boton
input Sirve para escribir <input type="text"> Sale un cuadro para escribir
form Hace un formulario <form> Sirve para meter datos
hr Hace una linea <hr> Separa el contenido
